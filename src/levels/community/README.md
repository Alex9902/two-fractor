# Niveles de la Comunidad

Aquí es donde deben ir los nuevos niveles creados por la comunidad mediante Pull Requests (PR).

## Instrucciones para contribuir un nivel

1. Copia la carpeta `src/levels/_template/` a esta carpeta con un nombre descriptivo (por ejemplo: `src/levels/community/mi-nivel/`).
2. Edita el archivo `manifest.ts` asegurándote de que `id` coincida exactamente con el nombre de la carpeta y que `type` sea `"community"`.
3. Implementa tu nivel dentro de `index.tsx`. Puedes añadir subcarpetas (componentes, hooks, assets) dentro de tu propia carpeta.
4. Abre una Pull Request en GitHub.
